🔐 Password Generator

A simple and secure password generator written in Java.

Features
Secure password generation using SecureRandom
Custom password length
Lowercase letters
Uppercase letters
Numbers
Symbols
Input validation
Guaranteed character categories
Password character shuffling
Requirements
Java 17 or later
How to run

Clone the repository:

git clone https://github.com/YOUR_USERNAME/password-generator-java.git


Move into the project directory:

cd password-generator-java


Compile the program:

javac src/PasswordGenerator.java


Run it:

java -cp src PasswordGenerator
